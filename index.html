연주 비교 노트
작품

    사용 순서

    1. 작품과 구간(악장·변주 등)을 만들어요
    2. ‘유튜브에서 녹음 찾기’로 녹음을 찾아 추가해요 (연주자·연도는 제목에서 읽어 채워요)
    3. ‘비교할 녹음 고르기’에서 비교할 녹음을 골라요
    4. 각 녹음에서 구간 시작 시간을 표시해요
    5. 같은 구간을 바꿔 들으며 비교해요

    1–8

    아직 녹음이 없어요‘+ 녹음 추가’를 눌러 유튜브나 유튜브 뮤직 링크를 붙여넣으세요.
    차트에 쓸 시간 정보가 아직 없어요비교 듣기 탭에서 녹음마다 구간 시작 시간을 표시하면 연주 시간과 템포 차이가 여기에 나타나요.

    전체 흐름

    막대 하나가 녹음 하나, 칸 하나가 구간이에요. 길수록 그 구간을 오래 연주했다는 뜻이에요. 칸을 누르면 그 구간이 선택돼요.

    구간별 상대 템포

    같은 구간을 연주한 길이로 계산했어요. 1.00×는 녹음들의 중간값이고, 위로 갈수록 빠른 연주예요. 반복을 생략하거나 넣은 녹음은 실제 템포보다 빠르거나 느리게 보일 수 있어요.

    유튜브에서 녹음 찾기

    앱 안에서 유튜브를 검색하려면 YouTube Data API 키가 한 번 필요해요. 무료이고, 키는 이 브라우저에만 저장돼요. GitHub에는 올라가지 않아요.

    키 없이 유튜브에서 직접 검색 ↗
    API 키 받는 방법 (5분, 한 번만)
    1. Google Cloud 콘솔 ↗에 구글 계정으로 들어가서 위쪽에서 새 프로젝트를 만들어요 (이름은 아무거나).
    2. 왼쪽 메뉴 API 및 서비스 → 라이브러리에서 YouTube Data API v3를 찾아 사용을 눌러요.
    3. API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키를 누르면 키가 나와요.
    4. 키를 누르고 키 제한을 설정해요: 애플리케이션 제한은 웹사이트로 하고 https://orgio98.github.io/*를 추가, API 제한은 YouTube Data API v3만 고르고 저장해요. 이렇게 하면 키가 남에게 보여도 다른 곳에서는 못 써요.
    5. 키를 복사해서 위 칸에 붙여넣어요.

    무료 사용량은 하루 검색 약 100번이에요. 결제 정보는 넣지 않아도 돼요.
