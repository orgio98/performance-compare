# 연주 비교 노트

같은 클래식 작품을 연주자, 지휘자, 오케스트라별로 나란히 듣고 비교하는 웹 앱이에요. 녹음은 유튜브나 유튜브 뮤직 링크로 추가해요.

**바로 쓰기:** https://orgio98.github.io/performance-compare/

## 할 수 있는 것

- **작품과 구간 만들기:** 작품을 악장, 변주, 주제 같은 구간으로 나눠요.
- **유튜브에서 녹음 찾기:** 작품명(과 연주자)으로 앱 안에서 유튜브를 검색하고, 결과를 눌러 바로 녹음으로 추가해요. 영상 제목과 설명에서 연주자, 지휘자, 오케스트라, 연도, 레이블, 라이브 여부를 읽어 채워 넣어요. 외부 재생이 막힌 영상은 미리 표시돼요. 검색하려면 YouTube Data API 키가 필요해요(아래 참고).
- **편성 짐작:** 작품명을 입력하면 편성(관현악, 협주곡, 독주곡, 실내악, 성악)과 독주 악기를 짐작해서 골라 둬요. 직접 바꿀 수도 있어요.
- **녹음 정보 적기:** 녹음마다 지휘자, 연주자(독주자), 오케스트라·앙상블, 녹음 연도, 레이블, 스튜디오/라이브 여부를 적어요. 편성에 맞는 칸만 보여요. 예를 들어 교향곡은 지휘자와 오케스트라, 피아노 소나타는 연주자만 보여요.
- **드롭다운으로 고르기:** 지휘자·연주자·오케스트라·레이블 칸에서 이 작품에 이미 쓴 이름, 다른 작품에 쓴 이름, 편성에 맞는 추천 목록(유명 지휘자, 오케스트라, 악기별 연주자, 현악4중주단, 성악가, 레이블)을 골라요. 한글이나 원어 철자로 검색할 수 있고, 목록에 없는 이름은 그대로 입력하면 돼요.
- **비교할 녹음 고르기:** 작품 안에서 지휘자, 연주자, 오케스트라, 형태, 연도 범위로 녹음을 걸러요. 걸러진 녹음은 하나씩 켜고 끌 수 있고, 연도순이나 지휘자순으로 정렬할 수 있어요.
- **같은 지점으로 전환:** 한 녹음을 듣다가 숫자키(`1`–`8`)를 누르면 다른 녹음의 같은 구간, 같은 비율 지점으로 넘어가요.
- **릴레이 듣기:** 고른 녹음들로 구간을 차례대로 이어서 들어요. '릴레이 구간' 번호를 여러 개 고르면 여러 구간을 이어서 듣고, 순서는 '구간마다 모든 연주'나 '연주마다 고른 구간' 중에서 골라요. 연주당 몇 초만 듣도록 정할 수도 있어요.
- **템포·시간 차트:** 녹음별 전체 흐름, 구간별 상대 템포, 구간별 연주 시간 표를 보여줘요.
- **해설 노트:** 연주자별 총평과 구간별 비교 메모를 적어요.

## 단축키 (비교 듣기 탭)

| 키 | 동작 |
|---|---|
| `1`–`8` | 그 번호 녹음의 같은 지점으로 전환 |
| `←` `→` | 이전/다음 구간 선택 |
| `M` | 재생 중인 녹음에서 선택한 구간의 시작을 지금 위치로 표시하고 다음 구간으로 이동 |
| `Space` | 재생/일시정지 |

## 유튜브 검색용 API 키

앱 안 검색은 YouTube Data API v3를 써요. 무료이고, 하루 검색 약 100번까지 쓸 수 있어요. 키는 쓰는 브라우저의 localStorage에만 저장되고 이 저장소에는 올라가지 않아요.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 새 프로젝트를 만들어요.
2. **API 및 서비스 → 라이브러리**에서 **YouTube Data API v3**를 사용 설정해요.
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**로 키를 만들어요.
4. 키 제한을 걸어요. 애플리케이션 제한은 **웹사이트**로 하고 `https://orgio98.github.io/*`를 추가해요. API 제한은 **YouTube Data API v3**만 골라요.
5. 앱의 **유튜브에서 녹음 찾기** 창에 키를 붙여넣어요.

키 없이도 **유튜브에서 직접 검색** 링크로 검색 결과를 열고, 링크를 복사해 **+ 링크로 추가**할 수 있어요.

## 데이터 저장

모든 내용은 지금 쓰는 브라우저의 localStorage에 저장돼요. 서버로는 아무것도 보내지 않아요. 다른 기기나 브라우저로 옮기려면 오른쪽 위 **내보내기**로 JSON 파일을 저장한 뒤 **불러오기**로 가져오세요. 브라우저 데이터를 지우면 기록도 함께 지워지니 가끔 내보내 두는 걸 권해요.

## 참고

- 유튜브 뮤직은 공식 API가 없어요. 대신 유튜브 뮤직 링크의 영상 ID가 유튜브와 같아서, 유튜브 공식 IFrame 플레이어로 재생해요.
- 업로더가 외부 재생을 막아 둔 영상은 앱 안에서 재생되지 않아요. 같은 녹음의 "Provided to YouTube by …" 음원 버전을 찾으면 보통 재생돼요.
- 상대 템포는 구간 길이로만 계산해요. 그래서 반복을 생략하거나 넣은 녹음은 실제 템포와 다르게 보일 수 있어요.
- `index.html`을 더블클릭으로 열면 유튜브가 재생을 막아요(오류 153). 직접 실행하려면 이 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`으로 여세요.

## 구성

빌드 과정 없이 `index.html` 파일 하나로 되어 있어요. 외부 라이브러리는 유튜브 IFrame Player API만 써요.
